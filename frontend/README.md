# Front-end — Doce Ateliê

React + TypeScript + Vite + Tailwind CSS.

Na pasta `frontend`, execute `npm ci` e `npm run dev`. Mantenha a API ASP.NET Core em execução em `http://localhost:5000`.

- `npm test -- --runInBand`: testes de componentes e integração com o cliente de serviços simulado.
- `npm run build`: verificação TypeScript e build de produção.
- `.env.example`: variável de configuração da URL da API.

Veja o [README principal](../README.md) para execução completa, persistência, endpoints e teste HTTP real.
